# 🚀 Avishkar Kedar - Portfolio Website

A modern, responsive, and interactive portfolio website showcasing my expertise in **Artificial Intelligence, Machine Learning, Data Science, and Full-Stack Development**.

Designed with a clean UI, smooth animations, and a recruiter-friendly layout to highlight my projects, skills, education, certifications, and experience.

---

## 🌐 Live Demo

🔗 **Portfolio:** https://avishkarkedar-portfolio.vercel.app/


# ✨ Features

- 🎨 Modern & Professional UI
- 📱 Fully Responsive Design
- ⚡ Built with Vite + React
- 🎭 Smooth Animations using Framer Motion
- 📂 Interactive Project Showcase
- 📜 Education & Certifications Timeline
- 📧 Contact Form
- 📄 Resume Download
- 🚀 Smooth Scroll Navigation
- 🎯 SEO-Friendly Structure
- 💻 Clean & Modular Code Architecture

# 🚀 Getting Started

## Clone the repository

```bash
git clone https://github.com/avishkarkedar11/portfolio.git
```

---

## Navigate to the project

```bash
cd portfolio
```

---

## Install dependencies

```bash
npm install
```

---

## Start development server

```bash
npm run dev
```

---

## Build for production

```bash
npm run build
```

---

## Preview production build

```bash
npm run preview
```
